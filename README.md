# 우리반 칭찬 기록부

학생들이 서로의 모범 행동을 칭찬으로 기록하는 학급용 페이지입니다.

## 기능

- **친구 칭찬하기**: 친구 번호·이름, 날짜, 칭찬 영역(학업·탐구, 배려·나눔, 봉사, 리더십, 질서·생활, 성실·책임, 기타), 구체적인 행동, 쓴 사람을 기록합니다.
- **누적 기록 공개 스위치(선생님 전용)**
  - 끄면 학생은 자기가 쓴 칭찬만 봅니다.
  - 켜면 학생도 전체 기록과 학생별 칭찬 횟수를 봅니다.
- **수정·삭제**: 학생은 자기 글만, 선생님은 모든 글을 고치거나 지울 수 있습니다.
- **시트로 내보내기(.xlsx, 선생님 전용)**: '전체 기록'과 '학생별 합계(영역별 횟수)' 두 개의 시트로 저장합니다.

## 실행 환경

`index.html`은 claude.ai 아티팩트로 실행하도록 만든 페이지입니다. 기록 저장, 사용자 구분, 파일 내려받기 기능은 claude.ai의 아티팩트 기능을 사용합니다. 그래서 이 파일을 GitHub Pages나 일반 웹서버에 그대로 올리면 기록이 저장되지 않습니다.

학생이 쓰려면 claude.ai 아티팩트의 **Share** 메뉴에서 학생들에게 글을 쓸 수 있는 권한으로 공유해야 합니다.
