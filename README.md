| 페이지 | 주소 | 하는 일 |

## 업데이트 (이미 칭찬 기록부를 쓰는 중이라면)

목표 트리를 쓰려면 구글 시트 코드를 한 번 바꿔야 합니다. 웹 앱 주소는 바뀌지 않습니다.

1. 칭찬 기록 구글 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 기존 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다.
3. 함수 목록에서 `setup`을 골라 **실행**합니다. 기존 칭찬 기록은 지워지지 않습니다.
4. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 누릅니다.
5. 시트의 `설정` 탭을 확인합니다.
   - **B4 교사용 비밀번호**: 자동으로 6자리 숫자가 만들어집니다. 원하는 값으로 바꿔도 됩니다.
   - **B5 기말고사 첫날**: 날짜를 넣으면 목표 트리에 D-day가 나옵니다.

## 기말고사 목표 트리

- 학생은 이름·번호, 장식 10가지(별, 하트, 방울, 종, 리본, 눈송이, 선물상자, 사탕지팡이, 달, 도토리) 중 하나, 목표와 실천 방법을 적어 트리에 답니다.
- **친구들에게는 이름과 장식만** 보입니다. 목표 내용은 서버에서부터 학생에게 보내지 않습니다.
- 학생은 자기가 쓴 기기에서 자기 목표를 다시 보고 고칠 수 있습니다. 도장을 받은 뒤에는 고칠 수 없습니다.
- **선생님 모드**: 페이지 맨 아래 '선생님 모드'에 교사용 비밀번호를 넣으면 모든 목표 내용이 보이고, 장식이나 표에서 **도장**을 찍을 수 있습니다.
- 도장을 받은 장식은 색이 살아나고 빛나며 '참' 도장이 붙습니다.
- 시트 `기말목표` 탭의 **도장 체크박스**를 직접 체크해도 똑같이 적용됩니다.
- 휴대폰·PC에서 **앱으로 설치**(홈 화면에 추가)할 수 있습니다.

## 목표 알림 (매일 아침 알림 · 한 번에 보내기)

학생이 앱을 설치하고 **알림 받기**를 누르면, 정한 시각에 학생마다 자기 목표가 담긴 알림이 갑니다.
예: `김민지의 기말고사 목표는! "매일 오답 정리하기" 입니다. 오늘도 한 걸음! (D-12)`

모든 설정은 목표 트리의 **선생님 모드 → 알림 보내기**에서 합니다.

| 항목 | 설명 |
| --- | --- |
| 매일 알림 보내기 | 켜고 끄기 |
| 보내는 시각 | 정한 시각 앞뒤 15분 안에 도착 |
| 시작일 · 종료일 | 이 기간에만 보냄. 종료일이 지나면 저절로 멈춤 |
| 알림 제목 · 내용 | `{이름}` `{목표}` `{디데이}` `{장식}`을 넣으면 학생마다 바뀜 |
| 도장 받은 학생 제외 | 목표를 이룬 학생에게는 매일 알림을 보내지 않음 |
| 지금 한 번에 보내기 | 알림을 켠 학생 모두에게 즉시 보냄 (예: 내일 수행평가 제출일) |

### 처음 한 번: Firebase 연결 (약 15분, 무료)

알림은 구글의 무료 알림 서비스 Firebase로 보냅니다. **개인 gmail 계정**으로 만드는 것을 권합니다(학교 계정은 막혀 있을 수 있음).

1. [Firebase 콘솔](https://console.firebase.google.com/) → **프로젝트 추가** → 이름 입력 → 애널리틱스는 꺼도 됨 → 만들기
2. 프로젝트 홈에서 웹 아이콘 **</>** → 앱 이름 입력 → **앱 등록** → 나오는 `firebaseConfig` 코드 복사
3. ⚙️ **프로젝트 설정 → 클라우드 메시징** → 맨 아래 **웹 푸시 인증서 → 키 쌍 생성** → 키 복사
4. ⚙️ **프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성** → JSON 파일 내려받기
5. 목표 트리 **선생님 모드 → Firebase 연결** 칸에 2·3·4번 내용을 붙여 넣고 **연결 저장**

서비스 계정 키는 구글 시트 스크립트 속성에만 저장되고, 학생 화면이나 저장소에는 절대 나오지 않습니다.

### 학생이 알림 받는 방법

- **안드로이드·PC(크롬/엣지)**: 목표를 단 뒤 **📣 매일 아침 내 목표 알림 받기** → 알림 허용. **📲 앱으로 설치** 버튼이 보이면 설치하면 더 편합니다.
- **아이폰**: iOS 16.4 이상에서, 사파리 **공유 → 홈 화면에 추가** 후 홈 화면의 '목표 트리' 아이콘으로 열어서 알림 받기를 누릅니다.
- 알림은 목표를 쓴 기기에서만 켤 수 있습니다. 학교에서 관리하는 기기는 알림이 막혀 있을 수 있습니다.

### 업데이트 후 꼭 할 일

`Code.gs`를 바꾼 뒤 `setup`을 한 번 실행하면 **외부 서비스 접속·트리거 권한**을 새로 묻습니다. 허용한 뒤 **새 버전으로 배포**하세요.

## 우리반 칭찬 기록부

- `설정` B2 체크박스: 학생에게 칭찬 누적 기록 보이기/숨기기
- `칭찬기록` 탭에서 직접 고치거나 지웁니다. `학생별 합계` 탭에 학생별·영역별 횟수가 자동으로 나옵니다.
- 저장 전 '장난 금지' 약속에 체크해야 저장됩니다.

## 처음부터 새로 설치할 때

1. 새 구글 시트 → **확장 프로그램 → Apps Script** → `Code.gs` 붙여 넣기 → `setup` 실행(권한 허용)
2. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자) → 웹 앱 URL 복사
3. `goals/index.html`, `praise/index.html`의 `SCRIPT_URL`에 URL 넣기
4. 저장소 **Settings → Pages**에서 Branch `main` / `(root)` 저장

## 알아둘 점

- 학생 로그인이 없어서 이름은 학생이 적은 그대로 저장됩니다. 링크는 학급 안에서만 나눠 주세요.
- `Code.gs`를 고친 뒤에는 꼭 **새 버전으로 다시 배포**해야 적용됩니다.
