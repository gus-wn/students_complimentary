# 우리반 칭찬 기록부

학생들이 서로의 모범 행동을 칭찬으로 기록하는 학급용 페이지입니다. 학생이 쓴 칭찬은 선생님의 구글 시트에 한 줄씩 쌓입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 학생이 쓰는 페이지 (GitHub Pages로 공개) |
| `apps-script/Code.gs` | 구글 시트에 붙여 넣는 연결 코드 |
| `claude-artifact.html` | claude.ai 아티팩트용 버전 (참고용) |

## 설치 순서 (처음 한 번, 약 10분)

### 1. 구글 시트 준비

1. [sheets.new](https://sheets.new)에서 새 구글 시트를 만들고 이름을 정합니다. 예: `2학년 3반 칭찬 기록`
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다.
4. 위쪽 함수 선택 칸에서 `setup`을 고르고 **실행**을 누릅니다.
   - 권한 요청 창이 뜨면 본인 계정을 고르고 허용합니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동**을 누릅니다. 본인이 만든 코드라 괜찮습니다.
5. 시트로 돌아가면 `칭찬기록`, `설정`, `학생별 합계` 시트가 생겨 있습니다.

### 2. 웹 앱으로 배포

1. Apps Script 화면 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴에서 유형 **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

### 3. 페이지에 URL 넣기

`index.html`에서 아래 줄을 찾아 따옴표 안에 웹 앱 URL을 붙여 넣습니다.

```js
const SCRIPT_URL = "";
```

### 4. GitHub Pages 켜기

1. 저장소 **Settings → General** 맨 아래에서 공개 범위를 **Public**으로 바꿉니다. (무료 계정은 공개 저장소만 Pages를 쓸 수 있습니다)
2. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 정하고 저장합니다.
3. 1~2분 뒤 `https://gus-wn.github.io/students_complimentary/` 주소로 열립니다. 이 주소를 학생들에게 나눠 주세요.

## 선생님이 조정하는 것

- **누적 기록 보이기/숨기기**: `설정` 시트의 B2 체크박스
  - 체크 해제: 학생은 이 기기에서 자기가 쓴 칭찬만 봅니다.
  - 체크: 학생도 전체 기록과 학생별 칭찬 횟수를 봅니다.
- **학급 이름**: `설정` 시트 B3에 적으면 페이지 오른쪽 위에 표시됩니다.
- **고치기·지우기**: `칭찬기록` 시트에서 직접 고치거나 행을 지웁니다.
- **집계**: `학생별 합계` 시트에 학생별·영역별 칭찬 횟수가 자동으로 나옵니다.

## 알아둘 점

- 학생 로그인이 없어서, '쓴 사람'은 학생이 적은 이름을 그대로 저장합니다.
- 링크를 아는 사람은 누구나 글을 쓸 수 있습니다. 링크는 학급 안에서만 나눠 주세요.
- 이 저장소에는 코드만 있고, 학생 기록은 선생님 구글 시트에만 저장됩니다.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 바뀐 내용이 적용됩니다.
