Firebase 연결 (처음 한 번만)
  1. Firebase 콘솔에서 프로젝트 추가 (애널리틱스는 꺼도 돼요)
  2. 프로젝트 홈에서 웹 아이콘 </> → 앱 이름 입력 → 등록 → 나오는 firebaseConfig 코드를 아래 1번 칸에 붙여 넣기
  3. ⚙️ 프로젝트 설정 → 클라우드 메시징 → 맨 아래 웹 푸시 인증서 → 키 쌍 생성 → 키를 2번 칸에 붙여 넣기
  4. ⚙️ 프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성 → 내려받은 JSON 파일을 메모장으로 열어 내용 전체를 3번 칸에 붙여 넣기

트리의 장식을 누르거나 아래 표에서 도장을 찍을 수 있어요. 도장은 구글 시트 '기말목표' 시트의 체크박스와 같아요.
